# 🐾 CoinPaws

CoinPaws is an engaging gamified web application that helps users earn daily passive micro-rewards to cover small everyday expenses like morning coffee, snacks, mobile data load, and daily transport fares. 

The application features a sleek, mobile-optimized dark UI designed with a pet-centric fintech theme, fluid animations, and real-time haptic/audio feedback frameworks.

---

## 🚀 Key Earning Vectors

*   **⛏️ Tap to Mine:** Centralized micro-hashing portal that allows users to mine points on their daily commute, powered by a high-frequency layout sharing ad-sponsor revenue pools.
*   **🚶 Walking Pedometer:** Integrated tracker leveraging hardware motion sensors to automatically count walking steps and convert physical activity directly into redeemable balances.
*   **🎮 MoneyPaws Arcade:** 
    *   *Paw Fruit Slicer:* Fast-paced mini-game converting casual scores directly into points.
    *   *Lucky Spin Wheel:* Weighted random reward wheel featuring bonus multipliers and jackpots.
    *   *Lucky Scratcher:* Virtual scratch cards simulating metallic overlay removal via finger touch movements.
*   **🎁 Mystery Loot Chests:** Separately timed daily mystery box roll drops backed by distinct probability tables.
*   **👥 Referral Engine:** Full invite bonus tracking matrix paying direct bonuses alongside passive lifetime commission tiers.

---

## 🛠️ Technology Stack & Architecture

*   **Frontend:** React 19, TypeScript, Vite, and Tailwind CSS (v4) for highly optimized responsive layouts.
*   **State & Sound Engines:** Custom declarative local storage persistence architecture paired with a Web Audio API procedural sound synthesis processor (zero physical asset overhead).
*   **Haptics Platform:** Device-independent mobile vibration engine designed specifically to deliver mechanical tactile feedback for user milestones.
*   **Validation Pipeline:** Managed automation suite via GitHub Actions inspecting structural linting rules and code building parameters.

## 📦 Getting Started & Local Development

### Prerequisites
Make sure you have **Node.js (v20+)** installed on your system.

### 1. Installation
Clone the repository and install the standard ecosystem dependencies:
```bash
npm install
```

### 2. Environment Configuration
Create a `.env.local` file in the root directory and append your secure development variables:
```env
GEMINI_API_KEY="your_private_gemini_api_studio_key"
APP_URL="http://localhost:3000"
```

### 3. Execution
Launch the local hot-reloading development server:
```bash
npm run dev
```
